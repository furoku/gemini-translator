# Support

Thank you for using Gemini Translator.

## How to get help

- For bugs: open an issue from [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md).
- For feature ideas: open an issue from [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).
- For security issues: please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Before opening an issue

1. Check the latest release and README.
2. Confirm your extension version in `extension/manifest.json`.
3. Include reproduction steps, expected behavior, and actual behavior.
4. Include browser version and target site URL.

## Response policy

- We aim to review new issues as soon as possible.
- Priorities are security, regressions, and user-impacting bugs.
